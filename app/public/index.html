How it works

  1. Create your Oracle Cloud account and start one server (the free one is enough to begin).
  2. Paste the one-click setup text while creating the server — MyDroidGrid installs itself in minutes. No coding, nothing to install by hand.
  3. Open your dashboard, create your admin account, create phones, press Start, and use them from your browser.

FAQ

Do I need a domain? No. Your server's own address is enough to start. A domain is only needed the day you open public signup.

Can I change a phone's Android version? Delete that phone and create a new one on the version you want — 2–3 minutes. RAM and cores can be changed anytime while the phone is stopped.

How many phones can my server run? That depends on its RAM and cores. The dashboard shows the real numbers live.
