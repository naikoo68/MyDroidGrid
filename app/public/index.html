How it works

  1. Install Ubuntu on the extra SSD (your Windows stays untouched).
  2. Run MyDroidGrid and create your admin account.
  3. Create phones, press Start, and use them from your browser.

FAQ

Do I need a domain? No. On localhost it runs free. A domain is only needed the day you open public signup.

Can I change a phone's Android version? Delete that phone and create a new one on the version you want — 2–3 minutes. RAM and cores can be changed anytime while the phone is stopped.

How many phones can my PC run? That depends on your RAM and cores. The dashboard shows the real numbers live.
